# mkit

A content-addressed version control toolkit written in Rust.

`mkit` is a generic content-addressed VCS — Git-like commits, refs, and
transports — plus a native, predicate-agnostic attestation subsystem
(in-toto v1 Statements wrapped in DSSE envelopes) that any downstream
service can attach witness signatures to commits with.

The v1 on-disk and wire formats are pinned by golden vectors under
`rust/tests/golden/` in the source repository.

### Specifications

Normative wire and on-disk formats. Read these if you are implementing
a compatible tool, a new transport, or a verifier.

- [Objects](/docs/spec/objects) — Blob, Tree, Commit, Remix,
  ChunkedBlob, Delta.
- [Index](/docs/spec/index) — the repo-local staging index.
- [Refs](/docs/spec/refs) — named tips with atomic CAS.
- [Packfile](/docs/spec/packfile) — packfile wire format.
- [Delta](/docs/spec/delta) — pack-internal delta encoding.
- [FastCDC](/docs/spec/fastcdc) — content-defined chunking.
- [Transport](/docs/spec/transport) — the seven-verb protocol shared
  by every transport.
- [RPC](/docs/spec/rpc) — RPC framing on top of the transport.
- [Signing](/docs/spec/signing) — commit and remix signing.
- [Attestations](/docs/spec/attestations) — in-toto v1 + DSSE.
- [External signer](/docs/spec/external-signer) — v1 stdio protocol
  for out-of-process signers (TPM, Secure Enclave, FIDO2, file).
