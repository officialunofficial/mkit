# Maintainers

Active maintainers of mkit are the public members of the
`officialunofficial` GitHub organisation:

- <https://github.com/orgs/officialunofficial/people>

That page is the source of truth. We do not duplicate it here so it
cannot drift.

## How to reach us

- **Security issues.** Use GitHub Security Advisories. See
  [`SECURITY.md`](SECURITY.md) for the full policy and timeline.
- **Bugs and feature requests.** File a public issue using the
  templates in `.github/ISSUE_TEMPLATE/`.
- **Everything else.** Open a discussion or a draft pull request.

We do not run a Slack, Discord, mailing list, or chat channel for
the project. Issues and pull requests are the primary venue.

## Becoming a maintainer

Maintainership is granted by existing maintainers based on a sustained
record of high-quality contributions and reviews. There is no formal
application process; if you are interested, the path is to ship good
patches and review other people's work.
