# WP-M0-12: ssh-frame session binding in `mkit-server` (`ssh` feature), transport-agnostic

- **Milestone/track:** M0
- **Base:** `feat/mkit-server`; **branch:** `mkit-server/wp-m0-12-ssh-binding`
- **Depends on:** M0-05b (upload/download sessions; review 01 split, R-72), M0-08 (the FS stores are used in tests)
- **Size:** L (~1000–1400 lines, of which ~half is tests ported from `mkit-cli`)

## Conventions

Same as WP-M0-01: TMPDIR, trailer, no CI polling, no proto change, a size check, workspace lints.

## Goal

Move the SSH-frame protocol server logic (`mkit.rpc.v1.ssh` framing: Hello handshake, per-verb dispatch, streaming
upload/download, per-connection budgets, the CAS-conflict reply) out of `mkit-cli` into `mkit-server` as one
**transport-agnostic, pipeline-backed** session driver. It works over any frame source and sink. The CLI ssh stdio
path (M0-13, blocking executor) and the native enc listener (M0-14, tokio) then share one implementation, and both
run on the pipeline (PRD §6.9, D23). **The wire bytes and error frames stay identical** (`mkit.rpc.v1.ssh` is
wire-frozen).

## PRD refs

§6.9 (ssh and enc use the same pipeline, storage, verification; stdio via a blocking executor; no change to the
frozen proto), §5.4 stage 1 (transport identity → principal), D23. `docs/specs/SPEC-TRANSPORT.md` §4.2 (SSH wire),
§4.2.1 (CAS conflict with current id in `details`).

## Scope

**IN:** `src/ssh/{mod.rs, session.rs, verbs.rs, budget.rs, tests.rs}`. Feature
`ssh = ["dep:mkit-rpc", "dep:buffa"]`, where `mkit-rpc = { version = "0.4", path = "../mkit-rpc" }` is already a
published crate, and `buffa` is already present via `connect`; don't add it twice. The traits are `FrameSource` and
`FrameSink`. Port the frame-level tests.

**OUT:** stdio reader thread and timeout (M0-13), enc session adapters (M0-14), removing the CLI copies (M0-13
deletes them).

## Design

```rust
#[cfg(feature = "ssh")]
pub mod ssh {
    #[derive(Debug)] pub enum FrameIoError { Eof, Timeout, Malformed, Io(crate::error::Redacted) }
    pub trait FrameSource: MaybeSend { fn next_frame(&mut self) -> impl Future<Output = Result<SshFrame, FrameIoError>> + MaybeSend; }
    pub trait FrameSink:   MaybeSend { fn send(&mut self, frame: &SshFrame) -> impl Future<Output = Result<(), FrameIoError>> + MaybeSend; }
    pub struct SessionConfig { pub server_id: String, pub stop_after_hello: bool, pub upload_limits: UploadLimits /* {MAX_BYTES_PER_CONN, MAX_FRAMES_PER_CONN} */ }
    #[derive(Debug, PartialEq, Eq)] pub enum SessionEnd { Clean, ProtocolError, Timeout, IoError }
    /// Runs Hello → verb loop. The pipeline must be configured with AuthMode::TransportIdentity; the caller supplies
    /// the transport principal (SshForcedCommand for stdio, TransportPeer{key} for enc).
    pub async fn serve_session<B, N, H, S, K>(pipeline: &Pipeline<B, N, H>, principal: Principal,
                                             src: &mut S, sink: &mut K, cfg: &SessionConfig) -> SessionEnd;
}
```

`SessionEnd` → CLI exit codes: `Clean` → `exit::OK`; `ProtocolError`/`Timeout` → `exit::PROTOCOL_ERROR`, matching
today's returns at `serve/mod.rs:241, 265, 276, 290`; a write failure after dispatch → `OK`, matching today's
`dispatch(..).is_err() → return exit::OK` at 296-298. Document the mapping in M0-13.

## Acceptance criteria

- [ ] `ssh` + `fs` features pull no tokio, axum or hyper into `mkit-server`'s own normal graph (the check prints `ok`).

- [ ] `mkit-cli` is unchanged in this WP.

## Risks / gotchas

- Today's upload reads chunk frames inline, inside `dispatch`, from the same reader (`serve/mod.rs:374-395`). The
  session must pull chunk frames from `src` while an upload is open. Keep that shape; don't spawn anything.
- Per-connection byte accounting (`frame_byte_estimate`) counts the `UploadPack.total_bytes` header estimate, not
  the chunk bytes of nested reads. Preserve it exactly; the budgets are documented in SPEC-TRANSPORT.
- `mkit-rpc` must not pull `std`-incompatible or wasm-hostile deps. `ssh` is native-only in practice, but gate the
  module `cfg(feature = "ssh")` only, not on the target.
