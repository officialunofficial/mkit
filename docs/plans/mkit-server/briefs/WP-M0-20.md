## Conventions

Same as WP-M0-01: TMPDIR, trailer, no CI polling, no proto change.

## Goal

Make the M0 exit criteria permanent CI gates, wired to trigger only on `main` (they run for the first time on the
final PR to `main`), and verify each one explicitly with a local run during the epic:

- conformance passes natively on FS + SQLite and S3 + SQLite, and on `wrangler dev`
- the existing CLI e2e tests pass
- nothing changes on the wire
- the **server-free CLI** criterion holds (it replaces the PRD's "tokio-free baseline" wording; `mkit-cli` already
  reaches tokio through connectrpc/reqwest clients): no axum, SQLite or `mkit-server-native` in the default
  `mkit-cli` graph, enforced by `scripts/check-cli-baseline.sh` (M0-13)

Record the evidence, update invariants, and mark M0 done in `docs/plans/mkit-server/README.md`.

## PRD refs

§8 M0 "Exit" (all four bullets), §5.1 (conformance suite runs in native CI and against `wrangler dev`).

## Exit checklist (run each and paste the tail of each output into the PR)

```bash
export TMPDIR="$HOME/.cache/mkit-test-tmp"; mkdir -p "$TMPDIR"
# 1. Conformance native FS+SQLite and S3+SQLite
cd rust && cargo nextest run -p mkit-server-native --all-features -E 'test(wire_fs_sqlite) | test(wire_s3_sqlite) | test(wire_fs_layout_bearer)'
# 2. Conformance on wrangler dev
cd .. && bash scripts/vcs-worker-conformance.sh
# 3. Existing CLI e2e (unchanged tests)
cd rust && cargo nextest run -p mkit-cli --all-features -E 'binary(ssh_e2e) | binary(ssh_retry_e2e) | binary(remote_dispatch_ssh) | binary(remote_dispatch_connect) | binary(serve_containment) | binary(serve_guard) | binary(roundtrip) | binary(push_pull_includes_pack) | binary(fetch_pull_all)'
cargo nextest run --workspace --all-features --profile ignored-lane --run-ignored ignored-only
# 4. No wire change
git diff --stat "$(git merge-base origin/main HEAD)" -- proto/ rust/crates/mkit-rpc/proto apps/repo-worker/proto   # must be empty
buf lint && buf breaking --against '.git#branch=origin/main'
# 5. Server-free CLI (graph check, plus the release-artifact check of M0-18 on a separate-invocation release build)
bash ../scripts/check-cli-baseline.sh && cargo build --locked -p mkit-cli && cargo build --locked -p mkit-cli --no-default-features
cargo build --release --locked -p mkit-cli --bin mkit --message-format=json-render-diagnostics > "$TMPDIR/mkit-build.jsonl" \
  && bash ../scripts/check-release-artifact-features.sh "$TMPDIR/mkit-build.jsonl" target/release/mkit
# 6. Full local CI
cd .. && just ci
```
