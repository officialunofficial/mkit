# WP-M0-15: Remove `--http`/`--listen-enc` from `mkit serve`; remove `mkit-transport-connect`'s `server` feature; docs

- **Milestone/track:** M0
- **Base:** `feat/mkit-server`; **branch:** `mkit-server/wp-m0-15-remove-cli-listeners`
- **Depends on:** M0-10, M0-14. Soft: WP-S1 merged first, since both edit `SPEC-TRANSPORT-CONNECT.md`.
- **Size:** M (mostly deletions; ~300 added / ~1500 deleted. Deletions don't count toward the size target, but keep
  the PR focused.)

## Conventions

Same as WP-M0-01: TMPDIR, trailer, no CI polling, no proto change, a size check, workspace lints. Pre-production
policy: the removals are allowed without deprecation (PRD §5.1 "the pre-production policy allows removing them").
Record them in `CHANGELOG.md` under **Removed**.

## Goal

Make `mkit serve` the ssh forced-command entry point only (D31). Delete the CLI's HTTP and encrypted listeners and
the now-duplicate native Connect server in `mkit-transport-connect`. Repoint docs, man page, completions and tests
to `mkit-server`.

## PRD refs

§5.1 (`-native` row: "The CLI's `mkit serve` stays only as the ssh forced-command entry point, and it drops `--http`
and `--listen-enc`"), §8 M0 last bullet, D31. Overview finding 3 (the `mkit-transport-connect` API removal forces a
0.MINOR bump).

## Risks / gotchas

- `serve/mod.rs` still contains the stdio loop and helpers after this WP. `enc.rs` used `handle_simple_verb`,
  `UploadDrain` and the others via `use super::*` (`enc.rs:12`); once enc.rs is gone, some helpers may become dead
  code only used by stdio. That's fine; M0-13 replaces them. Don't leave `#[allow(dead_code)]` behind; delete
  anything unused.
- Semver: `cargo semver-checks` runs only at tag time (`crates-publish.yml`). This PR doesn't bump versions, but
  the CHANGELOG note is required so WP-REL bumps 0.4 → 0.5.
- `rust/crates/mkit-transport-connect/README.md` is `include_str!`'d as crate docs (`lib.rs:3`), so doc tests there
  compile. Remove server examples.
