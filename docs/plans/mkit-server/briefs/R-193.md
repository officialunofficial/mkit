## Purpose

Uno's scanner receives metadata-only PRE_RECEIVE Inspect calls. To decide, it needs the bytes. It fetches the
advance's **raw added packs** over a private, capability-gated channel, decodes them itself with `mkit-core`, and
verifies the object ids against the Inspect request. Chunk membership comes from decoding manifests. The server does
no decoding or role classification for the scanner.

## A. Fixed

- Inspect stays metadata-only: no bytes inline (§6.4, §11).
- Hook signing per §7, with a fresh nonce per call and a stable `inspection_id`.
- Launch profile: sync-only, one batch per inspector, at most 4 inspectors.
- **Global denial (5.6a-1) is never bypassed:** retrieval must not serve bytes that an active block action denies.
- No existence oracle: every failure (unknown pack, wrong capability, expired, not part of this inspection) gives the
  same `not_found`.
- Default-off, Paid-only, with no activation before 4.18.

## B. Decided

1. **The capability.** For each Inspect call, the server mints a short-lived retrieval capability and places it in
   the request. It gets an **additive** `InspectRequest` field (a new message holding the endpoint path, the
   capability, its expiry and the ordered added pack ids with their lengths). hooks.v1 isn't released, so an additive
   field is fine: regenerate the transport, bump nothing.
   - The capability is a MAC under a **dedicated** retrieval key, rotatable with the active/retained model of the URL
     token keys. It must not reuse any other role's key; startup refuses reuse.
   - It binds: audience (the server origin), the `inspection_id`, repository identity, the exact pack ids, and an
     expiry of at most the hook timeout plus a small margin.
2. **The endpoint.** A private retrieval route on the server: native, plus a Worker mount on `vcs-worker`.
   - It requires **both** the capability **and** a request signed by a key in the configured scanner Ed25519
     allowlist (auth-v2 envelope, audience = server origin). The scanner key is a new role in the key matrix, and
     role/key reuse refuses startup.
   - It serves one bound pack per request, with bounded range support. It reads the staged pack bytes that the
     advance's upload tickets stored.
   - It never reads packs outside the capability, never serves blocked content, and sets no cache headers.
   - Workers Caching stays off on the route.
3. **Lifetime.** Retrieval works only while the capability is unexpired and the advance hasn't completed. After
   apply or abort it returns `not_found`, even with a valid unexpired capability. Choose the smallest check that
   proves this from existing ticket/advance state. If that needs new durable state, stop and escalate.
4. **Configuration.** Config grammar for the retrieval key(s), the scanner allowlist and the route enablement, native
   and Worker, all default-off. Missing or conflicting settings refuse startup when an inspector is configured with
   retrieval enabled. Update the `staging-uno.md` key table and `launch-operations.md` rotation row.
5. **Docs.**
   - Spec: an additive R-193 subsection in §11 or §7 defining the capability binding, the endpoint semantics and the
     no-oracle rules. Add a version-history row.
   - Finish row R-193 in `00-plan.md`, and add a registry row with deps on 5.5a (#1240) and 5.6a-1 (#1242).
   - CHANGELOG.

## D. Escalate (stop, commit, report)

- The lifetime check (B3) needs new durable state or a new key tag.
- The staged bytes aren't addressable by pack id before apply on either native or Worker.
- You'd pass 2,000 lines.

## Tests

- **The happy path:** the scanner fetches every added pack, decodes it and matches the Inspect ids. Native and Worker,
  with range reads.
- **Uniform `not_found` for:** wrong or missing capability, a wrong scanner key, expiry, a pack outside the
  capability, after apply, after abort, and blocked content.
- **Key-role reuse** refuses startup.
- **A stable `inspection_id` and capability across retries.** Decide whether retries re-mint the capability, and
  document it.
- **Default-off:** no route is mounted.
- **Budget:** the retrieval route's call and memory bounds are asserted.
