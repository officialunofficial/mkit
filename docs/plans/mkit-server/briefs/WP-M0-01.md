## Goal

Create the runtime-agnostic core crate `rust/crates/mkit-server` with the vocabulary every later WP builds on:

- repo and namespace identifiers, principals, the typed `Operation` model
- a transport-neutral error type with Connect-code mapping and redaction
- the async/runtime model (`MaybeSend`, `BoxFuture`, `Clock`, `Spawner`, `send_wrap`)
- a metrics trait

It must compile for native and `wasm32-unknown-unknown`, and is covered by the wasm dependency-graph check.

```rust
// src/rt.rs — PRD §5.2. Send on native; blanket on wasm.
#[cfg(not(target_arch = "wasm32"))] pub trait MaybeSend: Send {}
#[cfg(not(target_arch = "wasm32"))] impl<T: Send + ?Sized> MaybeSend for T {}
#[cfg(target_arch = "wasm32")]      pub trait MaybeSend {}
#[cfg(target_arch = "wasm32")]      impl<T: ?Sized> MaybeSend for T {}
// MaybeSync: same pattern with Sync.

#[cfg(not(target_arch = "wasm32"))]
pub type BoxFuture<'a, T> = core::pin::Pin<Box<dyn core::future::Future<Output = T> + Send + 'a>>;
#[cfg(target_arch = "wasm32")]
pub type BoxFuture<'a, T> = core::pin::Pin<Box<dyn core::future::Future<Output = T> + 'a>>;
// BoxStream<'a, T>: same pattern over futures_core::Stream.

/// Injected time source. Nothing in mkit-server may call SystemTime/Instant directly:
/// `Instant::now()` panics on wasm32 (see apps/mkit-worker-common/src/adapter.rs:55).
pub trait Clock: MaybeSend + MaybeSync { fn now_ms(&self) -> i64; }
#[cfg(not(target_arch = "wasm32"))] #[derive(Debug, Default, Clone, Copy)] pub struct SystemClock;
#[cfg(not(target_arch = "wasm32"))] impl Clock for SystemClock { /* SystemTime::now() -> ms */ }
/// Test clock with interior mutability (AtomicI64) usable on both targets.
#[derive(Debug, Default)] pub struct ManualClock { /* … */ }

pub trait Spawner: MaybeSend + MaybeSync { fn spawn(&self, fut: BoxFuture<'static, ()>); }

/// Make a MaybeSend future satisfy the `+ Send` bound generated connectrpc traits require.
/// PRD §5.2: the Workers adapter wraps the handler future once.
#[cfg(not(target_arch = "wasm32"))]
pub fn send_wrap<F: core::future::Future + Send>(f: F) -> F { f }
#[cfg(target_arch = "wasm32")]
pub fn send_wrap<F: core::future::Future>(f: F) -> send_wrapper::SendWrapper<F> { send_wrapper::SendWrapper::new(f) }
```

```rust
// src/op.rs — the typed Operation model. Procedure, OpKind and Commitment are #[non_exhaustive]: M1 adds
// BeginUpload / UploadPart / CompleteUpload / GetServerInfo and the `part:` commitment, M2 adds the epoch,
// visibility and URL-token RPCs, without reshaping Operation (reconciliation R-02).
#[non_exhaustive]
pub enum Procedure { ListRefs, ReadRef, UpdateRef, AdvanceRefs, PackExists, UploadPack, DownloadPack }
impl Procedure {
    pub const fn connect_path(self) -> &'static str;          // "/mkit.transport.v1.TransportService/UpdateRef" …
    pub fn from_connect_path(p: &str) -> Option<Self>;
    pub const fn is_write(self) -> bool;                       // UpdateRef, AdvanceRefs, UploadPack
    pub const fn is_streaming(self) -> bool;                   // UploadPack, DownloadPack
}
#[non_exhaustive] pub enum Commitment { Body(Hash), Pack { id: Hash, len: u64 } }  // parsed from Authorized.commitment; M1 adds Part
pub struct VerifiedAuth { pub signer: [u8; 32], pub replay_scope: Hash, pub fingerprint: Hash,
                          pub nonce: String, pub commitment: Commitment, pub expires_at_ms: i64 }
impl TryFrom<&mkit_core::write_auth::Authorized> for VerifiedAuth { /* hex decode; reject noncanonical */ }
pub struct RefUpdate { pub name: String, pub condition: RefWriteCondition, pub new: Hash }
#[non_exhaustive]
pub enum OpKind {
    ListRefs { prefix: String }, ReadRef { name: String }, UpdateRef(RefUpdate),
    AdvanceRefs { head: RefUpdate, packmap: RefUpdate },
    PackExists { key: PackKey }, UploadPack { key: PackKey, declared_len: u64 }, DownloadPack { key: PackKey },
}
/// Facts the Authorizer established, carried into `apply` as preconditions. Always `Default` in M0.
/// M2 (WP-2.6) sets `grant` so the pipeline can put `grant.epoch` into `Preconditions::grant_epoch`.
#[derive(Debug, Clone, Default)]
pub struct AuthzFacts { pub grant: Option<GrantRef>, pub owner: bool }
#[derive(Debug, Clone, Copy)] pub struct GrantRef { pub id: Hash, pub epoch: u64 }
pub struct Operation { pub repo: RepoId, pub principal: Principal, pub auth: Option<VerifiedAuth>, pub kind: OpKind,
                       pub authz: AuthzFacts }
impl Operation { pub fn procedure(&self) -> Procedure; }
```

```rust
// src/error.rs — transport-neutral; bindings map Code → Connect ErrorCode / ssh ErrorCode.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Code { InvalidArgument, Unauthenticated, PermissionDenied, NotFound, FailedPrecondition,
                ResourceExhausted, Aborted, Unavailable, Unimplemented, DeadlineExceeded, Internal, Unknown }
/// A typed error detail (Connect `ErrorDetail`): the fully qualified proto type name plus encoded bytes.
/// M3 (`AdmissionChallenge`), M4 (`PendingVerification`) and M5 (`RedactionNotice`) attach these.
#[derive(Debug, Clone, PartialEq, Eq)] pub struct ErrorDetail { pub type_name: String, pub value: bytes::Bytes }
#[derive(Debug, Clone, thiserror::Error)]
#[error("{public}")]
pub struct ServerError { code: Code, public: std::borrow::Cow<'static, str>, detail: Option<Redacted>,
                         http_status: Option<u16>, headers: Vec<(String, String)>, details: Vec<ErrorDetail> }
impl ServerError {
    pub fn new(code: Code, public: impl Into<Cow<'static, str>>) -> Self;
    pub fn invalid_argument(..) / unauthenticated(..) / permission_denied(..) / not_found(..)
       / failed_precondition(..) / resource_exhausted(..) / aborted_retryable(..) / unavailable(..) / unimplemented(..);
    /// Backend failure: fixed public message, detail kept only for server-side logging (issue #794 pattern).
    pub fn internal(public: &'static str, detail: impl core::fmt::Display) -> Self;
    /// Response shaping for the Connect binding (reconciliation R-03). Unused by M0 code paths, but covered by
    /// tests here and in M0-06: M3 returns HTTP 402 + challenge headers + `AdmissionChallenge` through these.
    /// Header names are validated as HTTP tokens; a name in `telemetry::SENSITIVE_HEADERS` is rejected
    /// (`debug_assert!` + dropped) so credentials can never be echoed.
    pub fn with_http_status(self, status: u16) -> Self;
    pub fn with_header(self, name: impl Into<String>, value: impl Into<String>) -> Self;
    pub fn with_detail(self, detail: ErrorDetail) -> Self;
    pub fn code(&self) -> Code; pub fn public_message(&self) -> &str; pub fn log_detail(&self) -> Option<&str>;
    pub fn http_status(&self) -> Option<u16>; pub fn headers(&self) -> &[(String, String)]; pub fn details(&self) -> &[ErrorDetail];
}
/// A string that never prints its contents via Debug/Display (redaction by construction).
pub struct Redacted(String);   // Debug => "Redacted(<n> bytes)"; `expose()` for the logging sink only
```

## Risks / gotchas

- `impl Future + MaybeSend` in trait return position: on native, `MaybeSend: Send` makes the future provably `Send`
  to callers through supertrait elaboration. Add one test that a generic function requiring `Send` accepts it
  (a compile-time test).
- `unreachable_pub` is warn-level workspace-wide and clippy runs with `-D warnings`. Every `pub` item must be
  re-exported from `lib.rs`.
- `send_wrapper` panics if the wrapped value is dropped or polled on another thread. That can't happen on
  single-threaded wasm. Document it next to `send_wrap`.
- Keep `mkit-core` at `default-features = false`. Feature unification in `cargo check -p mkit-server --target wasm32`
  covers only this package's graph, which is why the wasm check runs per crate.
