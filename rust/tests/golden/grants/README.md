# Grant fixtures

These files pin the grant statement, header, and owner signature formats
specified in [SPEC-WRITE-GRANTS](../../../../docs/specs/SPEC-WRITE-GRANTS.md).

The fixed secp256k1 and P-256 test seeds own real `0x` namespaces. Never
allowlist these namespaces on a shared or staging deployment. They are
public test credentials, not deployment owner keys.
